Atualização da tela de Movimentações

Arquivos alterados:
- index.php
- paginas/movimentacoes.php
- api/presencas.php
- assets/js/movimentacoes.js

Novos recursos:
1. Filtro por data inicial e final.
2. Botão para exportar CSV do resultado filtrado.
3. Botão para excluir uma movimentação individual.

Instalação:
- Faça backup dos arquivos atuais.
- Copie cada arquivo para a mesma pasta no projeto /var/www/html/portaria/.
- Se a pasta assets/js/ já existir, apenas adicione o arquivo movimentacoes.js.
- Depois atualize a página com Ctrl+F5.
